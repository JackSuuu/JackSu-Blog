我写日记有好几年了。

一开始，这只是一个倾诉的出口，一个存放情绪和日常的树洞。但随着时间推移，当我偶尔回头翻阅那些跨越了数年的文字时，我发现了一些奇妙的现象：

**同样的困惑，竟然在不同的年份反复出现；情绪的高低潮，似乎有着它自己隐秘的节律；而很多当时我以为一辈子都会记住的深刻感受，其实早已在记忆中模糊不清。**

日记，是我们对自己最诚实的记录。但传统的日记大多是“只写不读”的（Write-only）。当文字像流水账一样堆积在硬盘里，它们就成了一座座孤岛。我开始思考：**能不能把这些记录变得更可访问、更可交互？**

我的初衷是把日记和自己的信息进行一次“数字建模”。我想把散落在时间轴上的自己，聚集到同一个对话里，让过去的记录不再仅仅是积灰的存档，而是真正成为认识自己、观察自己的一部分。

**开发这个 APP，源于我对于自我的探索。它的核心主题是：把记录，变成观察。**

这就是 **mirror-self** 诞生的契机。它不仅是一个工具，更是一套帮助我理解自己的框架。

## 你的日记，只属于你：完全本地化的安全感

在介绍功能之前，我必须先谈谈**隐私**。

日记是最私密、最脆弱的文字，里面装着我们的焦虑、野心、软弱和不加掩饰的真实。市面上有很多出色的 AI 笔记软件，但当我想到要把这些文字上传到云端，交给某个商业公司的 API 去处理时，我退缩了。

**因此，mirror-self 从设计之初，就确立了一个铁律：完全本地运行。**

没有任何服务器，没有云端同步，没有任何数据上传，甚至不需要你配置任何 OpenAI 的 API Key。只要你的电脑能运行，它就能工作；哪怕拔掉网线，你依然可以和过去的自己深夜长谈。

在这个框架下，我组建了这样一个纯本地的技术栈：

- **Ollama**: 本地大语言模型引擎，支持 qwen2.5 等多种开源模型，负责理解和对话。
- **ChromaDB**: 本地向量数据库，存储所有日记的语义嵌入（Embeddings）。
- **nomic-embed**: 本地嵌入模型，用于精准的语义检索与相似度计算。
- **Textual TUI**: 纯终端 UI。不需要打开浏览器，在沉浸式的命令行界面中专注对话。

数据永远不离开你的设备。mirror-self 也是完全开源的，我认为可以安心地把最私密的文字交给它，是这一切发生的前提。

## 四种方式，重新认识自己

所有的记录，都是为了更好地认识自己。

mirror-self 将你多年的文字索引成本地向量数据库，并提供了四种不同的自我观察角度。从自由问答到跨年分析，让日记里的信息真正为你所用。

### F1 · chat：自由对话

想象一下，你可以用自然语言向自己的日记提问。
_“我去年这时候在担心什么？”“我对孤独的感受，这两年有没有发生变化？”_

通过语义检索配合本地 LLM，mirror-self 不是简单地给你返回几个关键词匹配的段落，而是整合了完整的上下文，给出一个基于你过去真实想法的、有逻辑的回答。这就仿佛在和一个最了解你的老朋友聊天。

### F2 · reflect：每日反思

我们很容易陷入日常的繁杂中，失去宏观视角的敏锐度。
开启每日反思模式后，mirror-self 会自动读取你近三个月的日记，并生成三个深度反思问题。它不会问泛泛的“你今天感觉怎么样”，而是基于你真实写下的内容，挑破那些你正在逃避的盲点，让你看见自己平时没有意识到的行为模式。

### F3 · compare：跨年对比

时间是最好的透镜。选择任意话题，你可以直观地对比它在不同年份里的演变轨迹。
_“我对‘工作’的态度，三年来发生了什么变化？”_
看着曾经的雄心勃勃、中途的迷茫疲惫，以及现在的自洽，时间线分析让“成长”这个抽象的词变得清晰可见。

### F4 · pattern：情绪规律

这是我个人最喜欢，也觉得最“温柔”的一个功能。
基于情绪相似性搜索，它能找出你反复出现的低落状态与触发因素。当你再次陷入某种熟悉的情绪泥沼时，它会温柔地提醒你：
**“这种感受，你曾经经历过。不用怕，上一次，你是这样走出来的。”**

## 三步开始，与自己对话

尽管底层使用了大模型和向量数据库，但我尽可能把 mirror-self 的使用门槛降到了最低。不需要账户，不需要复杂的环境配置。

**01 准备你的 Markdown 日记**
将你平时的日记整理成 Markdown 文件。按月份或章节命名即可，中英文混写完全支持，格式非常灵活。

**02 一键建立本地索引**
让 mirror-self 解析并分割你的日记，用本地嵌入模型生成向量，并存储到设备上的 ChromaDB 中。只需要在终端执行：

```plain
$ mirror-self init

```

**03 开始与自己对话**
启动任意模式，进入极简的终端 UI。抛开一切通知和干扰，开始面对真实的自己：

```plain
$ mirror-self chat

```

## 结语：照镜子的人

很多人说，写日记是在时间的长河里刻舟求剑。我们试图留住某一刻的自己，但水流太急，我们总是会遗忘。

mirror-self （镜中自我）不仅是一把捞起旧日记忆的网，更是一面跨越时间的镜子。它让我们在迷茫时，能向过去的自己寻求答案；在痛苦时，能从过去的自己那里获得经验与安慰。

如果你也和我一样，有着长期记录的习惯，并且渴望从这些记录中挖掘出关于“自我”的真相，欢迎来尝试一下 mirror-self。

把记录变成观察，也许，这就是我们走向内心自洽的第一步。
